# india-sales-data-analysis
# 🇮🇳 India Sales Data Analysis using Excel

## 📌 Project Overview
This project analyzes India Sales data to understand sales performance across different states, products, and time periods. The goal is to provide actionable insights for business growth using Excel dashboards.

## 📊 Dataset
- Source: Sales transaction data of India
- Contains: Order Date, State, Product, Sales Amount, Profit, Quantity

## 🛠️ Tools Used
- Microsoft Excel - Data Cleaning, Pivot Tables, VLOOKUP, SUMIFS
- Interactive Dashboard & Slicers
- Data Visualization

## 📈 Key KPIs Analyzed
- Total Sales & Total Profit
- State-wise Sales Performance
- Month-wise Sales Trend
- Top 5 Selling Products

## 💡 Key Insights
- Maharashtra & Karnataka have highest sales.
- Sales are highest in Q4 (Oct-Dec).
